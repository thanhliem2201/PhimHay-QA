PhimHay — Online Movie Website: Test Documentation

ASP.NET Core MVC (.NET 8), EF Core, SQL Server · Tested with Excel and Chrome/Edge DevTools · 09/2026

PhimHay is a movie website with registration and email verification, login, password recovery, search and filtering, streaming, comments, ratings, favorites, and admin management. I wrote full QA documentation for it as a practice exercise: a test plan, 74 test cases across 17 feature areas, and 9 bug reports written from running the app myself.

MetricResult
Test cases designed74, across 17 feature areas
Executed74 of 74 (63 Pass, 9 Fail, 2 Blocked)
Pass rate85.1%
Bugs found9 (3 High, 4 Medium, 2 Low severity)

Two of the three High-severity bugs: the Admin dashboard had no authorization check, letting any visitor or logged-in user open it directly by URL; and an invalid page number in the URL crashed the site with an unhandled exception.

  • Wrote a test plan covering scope, test types, environment, entry/exit criteria, and risks.
  • Designed test cases using equivalence partitioning, boundary value analysis, and error guessing (e.g. password length 7 vs. 8, page numbers 0/−1/9999).
  • Reviewed the source code to verify expected behavior where no requirements document existed.
  • Reported each bug with steps to reproduce, expected vs. actual result, severity, and evidence.

Repo: github.com/KhietLoi/PhimHay (team repo) · Test documentation available on request
